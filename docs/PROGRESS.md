# Çalışma deneyimi iyileştirmeleri

Kullanıcının verdiği değerlendirme, güncel `main` üzerinde kontrol edildi. Her adım testlerden sonra ayrı commit olarak `main`e gönderilir.

- [x] 1. Karşılama ve görsel önizleme, zengin hazır örnek, mobil hesap bilgisi; kurulum lockfile ve yerel API ortam değişkenleri.
- [ ] 2. Not içeriği/başlık/ders düzenleme, arama/etiketler, erişilebilir onay pencereleri ve özet dışa aktarma.
- [ ] 3. Uygulama cevaplarını değerlendirme, tekrar geri alma/karıştırma/zor kartlar/sesli okuma.
- [ ] 4. Sınav geçmişi, günlük hedef/seri ve ders ilerlemesi.
- [ ] 5. Word, PowerPoint, fotoğraf ve taranmış PDF içe aktarma; yerel üretici iyileştirmesi.
- [ ] 6. Son regresyon kontrolü ve kalan sınırlamaların belgelendirilmesi.

Zaten mevcut: çoklu dosya yükleme, sunucu için Vite API adaptörü, Gemini tekrar deneme/model yedeği. Bunlar tekrar yazılmıyor. Misafirler örneği ve yerel modu kullanabilir; ortak AI sunucusu için oturum kontrolü korunur ve giriş yolu açıkça gösterilir.
